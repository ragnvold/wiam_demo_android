# Loan Calculator Demo (Android)

Demo-приложение для тестового задания: экран калькулятора займа с расчетами и отправкой заявки на mock API.

## Как запустить

1. Открыть проект в Android Studio
2. Дождаться Gradle Sync
3. Запустить конфигурацию `app` на эмуляторе или устройстве (Android TODO+)
